# Security

Report suspected vulnerabilities privately to
[mail@ratspeak.org](mailto:mail@ratspeak.org), or use
[GitHub private reporting](https://github.com/ratspeak/ratspeak-handheld/security/advisories/new)
when available. Do not open a public issue for a security report.

Include the device, firmware version or commit, reproduction steps, and impact.
Use test identities and redacted logs, without private keys, credentials, or
message databases.
